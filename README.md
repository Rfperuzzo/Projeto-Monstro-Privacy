# Projeto Monstro — Política de Privacidade

Este repositório público contém somente o site estático da Política de
Privacidade do aplicativo Android Projeto Monstro e a automação necessária para
publicá-lo no GitHub Pages.

- Site: <https://rfperuzzo.github.io/Projeto-Monstro-Privacy/>
- Fonte canônica: `playstore/privacy` no repositório privado do aplicativo
- Publicação: GitHub Actions, sem rastreadores, cookies ou JavaScript

O código-fonte do aplicativo, seus artefatos de build e suas credenciais não
fazem parte deste repositório.
